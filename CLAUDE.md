# kanji-stroke-order MCP

Hosted MCP server under `apperceptive/kanji-stroke-order`. Returns KanjiVG SVG stroke order data for kanji characters. Part of the Apperceptive platform (Myers Media LLC).

## What this server does and does NOT do

**Does:** Character → raw KanjiVG SVG + stroke count. Pure data lookup.

**Does not (`get_stroke_order`):** Animate, color, parse, or render anything. The harness does that from the SVG data and the tool description.

**Also serves (prototype, branch `nihongoism-apps-prototype`):** two MCP Apps, a stroke player (`show_strokes`) and a kanji compass (`open_compass`), plus a relation graph built from KanjiVG. Their markup is built from `ui/` at build time and served as-is, never written by a model (ADR-024 B6). The runtime calls no model. See README § Nihongoism MCP Apps.

## Firestore

- **Project:** `kanjiism-65892` (shared with the Kanjiism app)
- **Collection:** `kanji`
- **Document key:** the kanji character itself (e.g. `犬`)
- **Relevant fields:**
  - `strokes.mincho.svg` — raw KanjiVG SVG inner content (mincho style, v1 only)
  - `strokes.kaisho.svg` — kaisho style (deferred to v2)
  - `stroke_count` — integer

## Source files

| File | Role |
|------|------|
| `src/index.ts` | Express HTTP server; `POST /mcp` → MCP transport; `GET /` health check |
| `src/server.ts` | Creates `McpServer` instance and registers tools |
| `src/data/firestore.ts` | Firebase Admin init + `getKanji(character)` |
| `src/tools/stroke-order.ts` | `get_stroke_order` tool: Zod schema, description, handler |
| `src/tools/apps.ts` | `show_strokes`, `open_compass` and the app-only `compass_*` tools; the two `ui://` resources |
| `src/graph/` | `relations.ts` (phonetic-series, shares-part, built-on, the ring, the P-025 wait rule), `questions.ts` (options labeled by relation), `graph.ts` (the bundle) |
| `src/data/strokes.ts` | Strokes for the apps: Firestore, or `KANJIVG_DIR` for local work |
| `data/graph.json` | Generated by `npm run graph`: KanjiVG parts, jōyō readings, grade and meanings for 2,136 kanji |
| `ui/` | The apps' sources; `ui/vendor/brush-engine.js` is the brush-kanji skill's engine, copied verbatim |
| `scripts/` | `build-graph.mjs`, `build-ui.mjs` (esbuild, to `ui-dist/`), `dev-host.html` (a bare test host, `DEV_HOST=1`) |

## Local dev

Requires:
- `service-account.json` — Firebase service account key for `kanjiism-65892` (gitignored)
- `.env` copied from `.env.example`

```bash
npm install
npm run dev        # runs via tsx (no build step needed)
```

Test with Inspector:
```bash
npx @modelcontextprotocol/inspector http://localhost:8080/mcp
```

## Deploy

```bash
gcloud run deploy kanji-stroke-order \
  --source . \
  --project kanjiism-65892 \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars FIRESTORE_PROJECT_ID=kanjiism-65892
```

No service account key in the container — Cloud Run uses ADC.
